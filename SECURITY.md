# Security policy

Secure360 handles cybersecurity incident reports for organisations in Cameroon. We take vulnerabilities seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting
(**Security → Report a vulnerability** on this repository). Include the affected component
(API, mobile app, web dashboard), steps to reproduce, and the impact you observed.

You will receive an acknowledgment within 5 working days. Please give us a reasonable time to fix the issue
before any public disclosure.

## Scope

This repository is an internship project. The demonstration environment contains fictitious data only.
Do not test against systems you do not own.
