# Reference documents (local only)

This folder holds the documents that people and AI tools work from. Its content is **git-ignored**: the SFC
specification is an internal document of Security First Cameroon, and the deliverables reference it. Move a
document to a committed folder only after the supervisor has approved publishing it in this public repository.

Expected content on your machine:

| Path | Document |
|---|---|
| `Secure360_Spec.html` | Specification v1.1 (SFC Incident Reporter) |
| `deliverables/Secure360_L1_Needs_Analysis_Report.pdf` | L1 v1.1 — personas, requirements, taxonomy, Decision Record D1–D9 |
| `deliverables/Secure360_L2_Architecture_Document.pdf` | L2 v1.0 — architecture, data model, RLS, security, API catalogue |
| `deliverables/Secure360_L2_Architecture_Diagrams.drawio` | L2 diagrams F01–F24 |
| `deliverables/Secure360_L3_UIUX_Mockups.pdf` | L3 v1.0 — design system, screens, journeys |
| `research/` | Week-by-week research notes (S1–S12) and early diagrams |

Precedence when documents disagree: **L1 Decision Record and L2 > research notes**, and the specification wins
unless L1/L2 record a deliberate change.
